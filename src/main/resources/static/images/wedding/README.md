couple photographs are used. Couple portraits await owner-supplied photographs.

`garden.jpg` was generated with the built-in imagegen tool on 2026-09-23 and
converted to JPEG for delivery. The source PNG remains in the generated-images
folder outside the repository. It is an illustration, not a venue photograph.
